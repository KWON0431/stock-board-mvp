# 연관주 보드 — 프로젝트 기획서

## 1. 문제 정의 (Problem)

개인 투자자가 특정 종목에 관심이 생겼을 때, 그 종목과 실제로 연동되어 움직이는 경쟁사·협력사·공급망 종목을 파악하려면 여러 커뮤니티·리포트·뉴스를 일일이 오가며 수작업으로 정리해야 한다. 이 과정은 평균 10~20분이 걸리고, 정리해둔 내용을 다시 보기 좋게 남겨두는 도구도 마땅치 않아 중간에 포기하는 경우가 많다.

## 2. 고객 페르소나 (Customer)

**손민준 (가상 인물, 27세, 사무직 직장인 개인 투자자)**
- 퇴근 후 30분~1시간 정도 짬을 내서 관심 종목을 살펴보는 초·중급 개인 투자자
- 특정 종목 뉴스를 보고 나면 "이 회사랑 관련된 다른 회사는 뭐가 있지?"라는 궁금증이 자주 들지만, 매번 검색엔진·커뮤니티를 오가며 정보를 짜깁기하느라 시간이 오래 걸림
- 엑셀이나 메모장에 정리해봐도 한눈에 보기 어렵고 금방 방치됨

> ⚠️ 아직 검증되지 않은 가설입니다. 1차 반복(4번 항목) 단계에서 실제 투자자 반응으로 이 페르소나가 맞는지 확인해야 합니다.

## 3. 시나리오 — As-Is → To-Be

| | As-Is (현재) | To-Be (연관주 보드 사용 후) |
|---|---|---|
| 행동 | 네이버 증권, 커뮤니티, 뉴스 검색을 오가며 연관주를 수작업으로 조사 | 종목 하나 검색 → AI 확장 버튼 클릭 |
| 소요 시간 | 10~20분, 중간 포기 잦음 | 30초~1분 |
| 결과물 | 엑셀·메모장에 텍스트로 흩어진 정보 | 관계선으로 시각화된 나만의 투자 지도, 자유 배치·메모 가능 |
| 재사용성 | 낮음 (다시 찾아보기 번거로움) | 보드에 계속 누적, 재방문 시 이어서 확장 가능 |

## 4. 솔루션 (Solution) — 현재 구현된 MVP

- 종목 검색 → 카드 생성 (시세 추이 미니 차트 포함)
- 카드의 **AI 확장 버튼**: 경쟁사(위)·협력사(오른쪽)·공급망(왼쪽) 각 3개씩 자동 확장, 반복 클릭 시 계속 확장
- 카드 손잡이로 **직접 연결선**을 긋고 관계(경쟁사/협력사/공급망/기타) 직접 지정 가능
- 자유 배치(드래그), 확대·축소(휠), 보드 이동(드래그), 메모 카드 추가
- GitHub → Vercel 배포 구조로 전환 완료

## 5. KPI (성공/실패 판단 기준)

MVP는 완성도가 아니라 **가설이 맞는지 검증하는 도구**이므로, 아래 지표로 "이 서비스가 실제로 필요한가"를 판단합니다.

| KPI | 정의 | 1차 목표 (가설 수립 단계) |
|---|---|---|
| AI 확장 클릭률 | 검색 후 실제로 AI 확장 버튼까지 누른 세션 비율 | 40% 이상 |
| 세션당 평균 카드 수 | 한 번 방문에서 만들어진 카드 개수 (지도를 "완성"까지 진행했는지의 대리 지표) | 5개 이상 |
| 검색 대비 방문 비율 | 총 방문 대비 실제 검색까지 이어진 비율 | 60% 이상 |
| 피드백 제출률 | 방문자 중 피드백을 남긴 비율 | 5% 이상 |

> 배포 사이트에 실제 측정 장치(Vercel KV 기반 이벤트 트래킹)를 붙였습니다. 아래 "실행 항목" 참고.

## 6. 1차 반복 계획 (Iteration Plan)

1. 배포 URL을 팀원 각자 지인 투자자 3명 이상에게 공유 (최소 20세션 확보 목표)
2. 최소 5개 이상의 피드백 텍스트 수집 (사이트 내 피드백 위젯 사용)
3. 수집된 KPI와 피드백을 바탕으로:
   - AI 확장 결과가 부정확하다는 피드백이 많다면 → 프롬프트/검색 정확도 개선
   - "카드가 너무 많아져 헷갈린다"는 피드백이 많다면 → 자동 정렬/그룹 접기 기능 검토
   - 확장 클릭률이 낮다면 → AI 확장 버튼의 위치·문구 개선
4. 개선 내용과 "무엇을, 왜 바꿨는지"를 기록해 발표 영상의 "반복 결과" 파트에 포함

## 7. 아직 남은 리스크 / 한계

- 페르소나·문제 정의는 아직 실제 사용자 인터뷰 없이 세운 가설 단계
- KPI 측정은 Vercel KV 연동이 되어 있어야 실제로 집계됨 (README 참고)
